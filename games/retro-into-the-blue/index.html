🎮 Play Into the Blue Online Free

Into the Blue is a match-three puzzle game for the Nintendo Game Boy, first released in 2018. Panels rise from the bottom of the screen — slide them around and line up three or more to clear them before the stack reaches the top.

How to play: Click the Start button in the player below. Move the cursor with the arrow keys and swap panels to line up three or more in a row. Fullscreen is available from the player menu. No download, no sign-up. On mobile, use the on-screen gamepad.

Keyboard: Arrow keys = D-pad, X = A button, Z = B button, Enter = Start, Shift = Select. The emulator menu (top-right) offers save states, fullscreen and controls.

About Into the Blue

Into the Blue (2018) by Jonas Fischbach is a free homebrew match-three puzzle game for the Game Boy. Panels rise from the bottom to the top and can be moved with the cursor like in a sliding puzzle. Line up three or more panels in a row or column to clear them. It runs here in your browser with the Gambatte emulator core via EmulatorJS.
