# Retro section — credits & licences

The Retro section of game.aifly.tools plays real Game Boy / Game Boy Color
homebrew games in the browser, using the EmulatorJS emulator. **No ads are
shown on any Retro page** — the homebrew games here are shared for
non-commercial use, so this section carries no advertising at all
(no AdSense, no in-game ads).

## Emulator

- **EmulatorJS v4.2.3** — https://github.com/EmulatorJS/EmulatorJS
  Licensed under the **GNU General Public License v3.0**. The full licence
  text is in `retro/LICENSE`. Original copyright and licence notices are
  kept in the shipped files. Only the files needed to run the Game Boy /
  Game Boy Color cores are shipped (loader, minified emulator bundle,
  gambatte + mGBA wasm cores, English localisation) — the full 290 MB
  release was pruned to ~5 MB.
- **Gambatte core** (Game Boy / Game Boy Color) — GPL-2.0.
  https://github.com/libretro/gambatte-libretro
- **mGBA core** (Game Boy Advance, included for future GBA games) — MPL-2.0.
  https://github.com/libretro/mgba

## Not included

- **Tobu Tobu Girl / Tobu Tobu Girl Deluxe** (Simon Larsen / Tangram Games,
  MIT code + CC BY assets) — not included: no prebuilt ROM is published in
  the GitHub repos or releases, and the itch.io download requires a
  name-your-own-price purchase flow; the source only builds with the
  obsolete GBDK 2.96a toolchain. The games can be added later if a
  distributable ROM becomes available.
- **Dangan GB / Goodboy Galaxy** — not included: no redistribution statement
  from the authors. Goodboy Galaxy is linked from the hall's promotion
  material only via its itch.io page.
